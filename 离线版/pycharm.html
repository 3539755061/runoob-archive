1. PyCharm 教程原文↗

PyCharm 是由 JetBrains 公司开发的一款专门用于 Python 编程的集成开发环境（IDE）。

PyCharm 拥有 Microsoft Windows、macOS 和 Linux 版本。

PyCharm 社区版在 Apache 许可证下发布，提供代码分析、图形化调试器，集成测试器、集成版本控制系统。

目前，PyCharm IDE 的社区版和专业版将合并为统一版本。

Pycharm 的目标市场是 Python IDE，主要竞争者包括 PyDev，Komodo IDE。

PyCharm 的主要功能

  • 1. 代码编辑与自动补全：PyCharm 提供了智能的代码编辑功能，包括语法高亮、代码自动补全、代码片段生成等。这些功能可以帮助开发者更快地编写代码，并减少拼写错误。

  • 2. 调试与测试：PyCharm 内置了强大的调试工具，允许开发者逐步执行代码，查看变量的值，并设置断点。此外，它还支持单元测试和集成测试，帮助开发者确保代码的质量。

  • 3. 版本控制集成：PyCharm 支持多种版本控制系统，如 Git、SVN 和 Mercurial。开发者可以直接在 IDE 中进行代码的版本管理，包括提交、拉取、合并等操作。

  • 4. 数据库工具：PyCharm 提供了数据库工具，允许开发者直接在 IDE 中连接和管理数据库。支持多种数据库系统，如 MySQL、PostgreSQL、SQLite 等。

  • 5. 插件与扩展：PyCharm 支持丰富的插件和扩展，开发者可以根据自己的需求安装各种插件，如 Django 支持、Docker 集成、Markdown 编辑器等。

PyCharm 的版本

PyCharm 有两个主要版本：

1. PyCharm Community Edition

这是 PyCharm 的免费版本，适合 Python 初学者和小型项目。它提供了基本的 Python 开发功能，但不包括一些高级功能，如数据库工具和 Web 开发框架支持。

2. PyCharm Professional Edition

这是 PyCharm 的付费版本，适合专业开发者和大型项目。它包含了所有 Community Edition 的功能，并增加了对 Web 开发框架（如 Django、Flask）、数据库工具、科学计算工具等的支持。

目前，PyCharm IDE 的社区版和专业版将合并为统一版本。

安装 PyCharm

Windows 系统
  1. 双击下载的安装文件（.exe）。
  2. 在安装向导中，选择安装路径，建议使用默认路径。
  3. 勾选"创建桌面快捷方式"以便快速启动 PyCharm。
  4. 点击 "Install" 开始安装。
  5. 安装完成后，点击 "Finish" 退出安装向导。

macOS 系统

  1. 打开下载的 .dmg 文件。
  2. 将 PyCharm 图标拖拽到 "Applications" 文件夹中。

  3. 在 "Applications" 文件夹中找到 PyCharm，双击启动。

Linux 系统

  1. 解压下载的 .tar.gz 文件。 
    tar -xzf pycharm-*.tar.gz
  2. 进入解压后的目录，找到 bin 文件夹。 
    cd pycharm-*/bin
  3. 运行 pycharm.sh 启动 PyCharm。 
    ./pycharm.sh

4. PyCharm Windows 安装原文↗

PyCharm 是 JetBrains 出品的 Python 集成开发环境（IDE），拥有智能代码补全和图形化调试功能，支持 Windows /macOS/ Linux 全平台。。

PyCharm 是一套写代码、跑程序、排错、管理项目、协作一体化工具，是目前行业最主流的 Python 开发工具。

本文介绍 PyCharm 的完整安装步骤，从访问官网下载到完成安装和首次启动配置。

整个过程只需依次点击「下一步」并按需勾选推荐设置，适合 Python 开发者快速搭建开发环境。

安装步骤

以下为 Windows 系统下的安装流程，macOS 和 Linux 的步骤类似。

示例版本为 PyCharm Community Edition 2026.x。

第 1 步：进入 PyCharm 官网

在浏览器中访问 JetBrains 官方网站的 PyCharm 产品页面：https://www.jetbrains.com/zh-cn/pycharm/。

第 2 步：点击「下载」

进入官网后，点击页面上的 「下载」按钮，进入下载页面。

第 3 步：选择操作系统并下载

在下载页面中，选择你的操作系统（Windows/macOS/Linux），然后点击下载按钮。

页面默认提供两个版本的下载入口：Professional（专业版）和Community（社区版）——社区版免费且满足大多数 Python 开发需求。

第 4 步：双击运行安装程序

下载完成后，在文件资源管理器中找到下载的安装程序（如 pycharm-community-2026.x.x.exe），双击运行。

第 5 步：欢迎界面点击「下一步」

安装向导启动后，在欢迎界面直接点击 Next（下一步）继续。

第 6 步：选择安装目录

选择 PyCharm 的安装目标文件夹。

默认路径通常为 C:\Program Files\JetBrains\PyCharm Community Edition 2026.x，你也可以点击 Browse（浏览）自定义安装位置。

确认后点击「下一步」。

第 7 步：勾选安装选项

在安装选项界面中，建议按如下配置勾选。

各项选项的作用如下：

选项 说明 建议
Create Desktop Shortcut（创建桌面快捷方式） 在桌面生成 PyCharm 快捷方式图标 推荐勾选，方便快速启动
Add "Open Folder as Project"（右键菜单） 在文件资源管理器右键菜单中增加 PyCharm 入口 推荐勾选，可直接打开项目文件夹
Add to PATH（添加到环境变量） 可在终端中使用 pycharm 命令启动 IDE 按需勾选，命令行重度用户推荐
Associate .py files（关联 .py 文件） 将 PyCharm 设为 .py 文件的默认打开方式 推荐勾选，双击 .py 文件即可在 PyCharm 中编辑

第 8 步：开始安装

确认开始菜单文件夹名称（保持默认即可），然后点击 Install（安装）开始安装。

等待安装进度条完成，此过程通常需要 1-3 分钟。

第 9 步：完成安装

安装完成后，勾选 Run PyCharm 可立即启动 IDE。

然后点击 Finish（完成）结束安装向导。

安装完成后建议重启电脑，确保 PATH 环境变量和文件关联完全生效。

首次启动 PyCharm 后，完成以下配置可以提升日常使用体验。

配置项 操作 说明

键盘映射 推荐使用默认的 IntelliJ 方案 如需匹配其他编辑器的快捷键，可在下拉框中切换（如 VS Code、Eclipse）

如果 IDE 提示 "No Python interpreter configured"，说明 PyCharm 没有找到 Python。前往 Settings → Project → Python Interpreter，点击齿轮图标选择 Add，然后浏览到 Python 的安装路径（如 C:\Users\用户名\AppData\Local\Programs\Python\Python312\python.exe）。

常见问题解答

1. PyCharm 启动时提示"No Python interpreter configured"怎么办？

这意味着 PyCharm 没有检测到 Python 解释器。你可以手动添加解释器：

  1. 打开"文件 -> 设置"（Windows/Linux）或"PyCharm -> 设置"（macOS）。
  2. 在左侧菜单中选择"项目: <项目名称> -> Python 解释器"。
  3. 点击右上角 "添加解释器"。
  4. 选择已安装的 Python 解释器路径。

2. 如何安装第三方库？

在 PyCharm 中，你可以通过以下步骤安装第三方库：

  1. 打开"File -> Settings"（Windows/Linux）或"PyCharm -> Preferences"（macOS）。
  2. 在左侧菜单中选择"项目: <项目名称> -> Python 解释器"。
  3. 点击右下角的"+"按钮，搜索并安装所需的库。

  • 项目 venv：虚拟环境默认存储在项目目录下的 venv 文件夹。

11. PyCharm 代码重构原文↗

代码重构是指在不改变代码外部行为的前提下，优化代码内部结构的过程。

重构的目的是提高代码的可读性、可维护性和可扩展性，而不是添加新功能或修复 Bug。

PyCharm 为 Python 开发者提供了一套强大且安全的自动化重构工具，让重构变得高效且不易出错。

常用重构操作速览

以下是 PyCharm 中最常用的重构操作及其快捷键对照表。

重构操作 快捷键 功能说明
Rename Shift + F6 重命名变量、函数、类、文件等符号，自动更新所有引用
Extract Variable Ctrl + Alt + V 将选中的表达式提取为变量
Extract Method Ctrl + Alt + M 将选中的代码块提取为独立的方法或函数
Extract Constant Ctrl + Alt + C 将选中的字面量提取为常量

重构注意事项

虽然 PyCharm 的重构工具非常可靠，但在重构时仍需注意以下几点。

  • 重构前确保代码已提交到版本控制系统，以便出现意外时可以回滚。
  • 重构后立即运行已有的单元测试，确保行为没有改变。
  • 一次只做一种重构操作，避免同时修改过多内容导致混淆。
  • 如果重构涉及公共 API，请确认所有调用方都已纳入重构范围。

        def test_brake_below_zero(self):
            """测试刹车不会让速度低于 0"""
            # 先加速到 20
            self.car.accelerate(20)
            # 刹车 50，速度应该被限制在 0
            result = self.car.brake(50)
            self.assertEqual(result, 0,
                             "速度不应低于 0")

        def test_brake_with_zero(self):
            """测试减速量为 0 时应抛出异常"""
            with self.assertRaises(ValueError,
                                   msg="减速量为 0 应抛出 ValueError"):
                self.car.brake(0)


    # 当脚本直接运行时执行测试
    if __name__ == "__main__":
        unittest.main()

    PyCharm 可以自动识别测试类和测试方法，测试类名以 Test 开头，测试方法名以 test_ 开头是 Python 测试的命名约定。

    14. PyCharm 包管理原文↗

    安装完成后，新包会出现在已安装列表中，并且立即可用。

    搜索包时，PyCharm 会从 PyPI 仓库获取最新信息，包括包的描述、版本和依赖关系，帮助你做出选择。

    使用内置终端（Terminal）安装包

    如果你更习惯命令行操作，PyCharm 内置的 终端（Terminal） 工具窗口是一个绝佳选择。

    打开终端

    点击底部工具栏的 Terminal 标签，或使用快捷键 Alt + F12 打开内置终端。

    终端会自动激活当前项目的虚拟环境，命令提示符前面会显示环境名称。

    常用 pip 命令

    # 安装单个包
pip install requests

# 安装指定版本的包
pip install requests==2.28.0

# 同时安装多个包
pip install requests flask numpy

# 升级已安装的包到最新版本
pip install --upgrade requests

# 卸载包
pip uninstall requests

# 查看已安装的所有包
pip list

# 查看某个包的详细信息
pip show requests

    PyCharm 的内置终端与外部终端完全一致，支持所有 pip 命令和系统命令，且与虚拟环境无缝集成。

    管理虚拟环境

    虚拟环境是 Python 开发的核心实践，它确保每个项目拥有独立的依赖空间，互不干扰。

    新建虚拟环境

    在创建新项目时，PyCharm 默认会提示你创建一个新的虚拟环境。

    你也可以在已有项目中手动创建：

    1. 打开 设置。
    2. 查看已经有的虚拟环境。
    3. 选择 添加解释器，指定环境存放位置和基础 Python 解释器。
    4. 点击 确认 完成创建。

    切换到 Conda 环境

    如果你使用 Anaconda 或 Miniconda 管理 Python 环境，PyCharm 也提供原生支持。

    1. 在 Python Interpreter 设置页面点击齿轮图标，选择 Add...。
    2. 左侧选择 Conda Environment。
    3. 选择 Existing environment，PyCharm 会自动检测系统中已安装的 Conda 环境。
    4. 从下拉列表中选择目标环境，点击 OK 完成切换。

    切换虚拟环境后，PyCharm 会自动重新索引包列表。请耐心等待索引完成，否则代码补全和类型检查可能不准确。

    requirements.txt 自动检测

    requirements.txt 是 Python 项目中最常见的依赖声明文件，PyCharm 对其有智能的支持。

    自动检测与提示

    当你打开一个包含 requirements.txt 文件的项目时，如果 PyCharm 检测到文件中的某些包尚未安装，编辑器顶部会出现一个醒目的提示栏。

    提示内容类似于："Package requirements 'requests', 'flask' are not satisfied"。

    点击提示栏中的 Install requirements 链接，PyCharm 会自动调用 pip 安装所有缺失的包。

    自动生成 requirements.txt

    你也可以让 PyCharm 帮你生成 requirements.txt 文件。

    在终端中执行以下命令：

    # 将当前虚拟环境中所有已安装的包导出到 requirements.txt
pip freeze > requirements.txt

    之后其他开发者拿到项目时，只需执行 pip install -r requirements.txt 即可一键安装全部依赖。

    建议将 requirements.txt 纳入 Git 版本控制，这样团队成员和 CI/CD 流水线都能基于相同的依赖环境进行开发和构建。

    • 数据库未迁移：首次运行需执行 python manage.py migrate

    创建 Django 应用

    创建新应用

    在 PyCharm 的终端中输入：

    python3 manage.py startapp myapp

    将应用添加到 settings.py 的 INSTALLED_APPS 中:

    INSTALLED_APPS = [
    ...
    'myapp',
]

    在项目 urls.py 中包含应用路由：

    实例

    from django.contrib import admin
    from django.urls import path

    urlpatterns = [
        path('admin/', admin.site.urls),
        path('myapp/', include('myapp.urls')),
    ]

    应用目录结构

    • migrations/：数据库迁移文件
    • admin.py：管理后台配置
    • apps.py：应用配置
    • models.py：数据模型定义
    • tests.py：测试代码
    • views.py：视图函数

    myapp 目录下配置 URL 路由

    打开 myapp/models.py，定义模型。例如：

    实例

    from django.db import models

    class Post(models.Model):
        title = models.CharField(max_length=200)
        content = models.TextField()
        created_at = models.DateTimeField(auto_now_add=True)

        def __str__(self):
            return self.title

    保存后，运行 python manage.py makemigrations 和 python manage.py migrate 以更新数据库。

    创建视图和 URL：

    在 myapp/views.py 中定义视图：

    实例

    from django.shortcuts import render
    from .models import Post

    def post_list(request):
        posts = Post.objects.all()
        return render(request, 'myapp/post_list.html', {'posts': posts})

    在 myapp/urls.py（需要手动创建）中配置 URL：

    实例

    from django.urls import path
    from . import views

    urlpatterns = [
        path('', views.post_list, name='post_list'),
    ]

    在项目根目录创建 DjangoProject/templates/myapp/ 文件夹，然后在改文件夹下创建 post_list.html：

    实例

    <!DOCTYPE html>
    <html>
    <head>
        <title>Post List</title>
    </head>
    <body>
        <h1>Posts</h1>
        <ul>
            {% for post in posts %}
                <li>{{ post.title }} - {{ post.created_at }}</li>
            {% empty %}
                <li>No posts available.</li>
            {% endfor %}
        </ul>
    </body>
    </html>

    确保 settings.py 中的 TEMPLATES 设置包含正确的模板目录：

    TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],
        ...
    }
]
