# runoob（菜鸟教程）板块分组与适用性归档 · 2026-11-13

把 runoob.com 首页「全部教程」的 12 个官方板块、150 个教程入口重新按用途归并为 9 组，
逐条抓取首页核验可达性、章节规模、在线运行与版本时效，给出适用性评级。

## 四条主要结论

1. **能当第一入口的约 30%（45 条）**，集中在语言语法、前端基础、数据工具；
   「推荐 + 可用」合计 101 条，接近三分之二。
2. **越新的技术教程越薄**：语言与前端基础 60–99 节，Agent / Next.js / CMake 多在 7–24 节，
   新板块适合当导览，不适合当教材。
3. **旧入口没有下线**：Vue 2 与 Vue3、Bootstrap 4 与 5、AngularJS 与 Angular 同时列在首页，
   选课要按「时效」列走，不能按首页顺序走。
4. **示例版本普遍停在 2012–2015**：Python3 首章打印 3.3.2、Vue 页自述 2.1.8、
   Swift 页自述 3.0.2、Android 页自述 2015 年撰写。语法仍成立，但「照抄能跑」要打折扣。

## 离线版（`离线版\index.html`）

- **范围**：4,851 个章节（150 篇教程侧栏里能枚举到的全部小节），抓取成功 4,419 个唯一页面，合并为 150 个长页。
- **形态**：每页 = 教程标题 + 可展开目录 + 按侧栏顺序排列的章节；保留代码块、表格、配图与原文强调，
  去掉站点导航、广告、评论、分享与「开始测验」等外链块。
- **资源**：5,804 张正文配图本地化到 `离线版\img\`，样式在 `离线版\css\offline.css`，页面不引用任何外网资源，
  断网可读。
- **体量**：约 472 MB（HTML 70 MB + 配图 400 MB）。
- **入口**：双击 `离线版\index.html`，按 A–I 九个分组进入；每篇顶部有「返回总索引」，章节目录可折叠。
- **已知缺口**：55 张站外图片（tutorialspoint、七牛云等）与原站已删的图片未能本地化，页面上仍指向原地址，联网时可见。

## 复核方式

每条结论都可回到三个点：表内链接（可点）、页面左侧目录（数章节）、教程简介原文
（搜「基于 … 版本」「… 年」）。阅读版的「01 说明」与「14 附录」写明了评级口径与局限。

## 局限

- 适用性评级基于每个教程的**首页与侧栏**，未逐章通读；章节数是目录链接数，反映规模不等于质量。
  （离线版已抓取全部章节正文，可用于自行核对。）
- 不做逐句内容核对：只判断「值不值得作为入口」，不判断某段代码/API 是否已废弃。
- 「参考手册」是另一套页面（6 条），不在 150 条统计内。
- 时效判断含行业共识（如 AngularJS 2021-12 结束支持），页面本身不会写这些。
- 站点结构会变，150 条是 2026-11-13 的快照。
